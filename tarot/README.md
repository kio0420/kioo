# 星語塔羅

純前端的繁體中文塔羅網站，不需要安裝或建置，直接用瀏覽器開啟 `index.html` 即可。

## 功能
- **牌義圖鑑**：78 張牌（大阿爾克那 22 張、小阿爾克那 56 張），每張都有正位與逆位解釋、關鍵字、牌面描述，以及感情和事業的解讀；可以依花色篩選或用關鍵字搜尋。
- **塔羅占卜**：8 種牌陣，分別是單張牌、是非題、時間之流（過去／現在／未來）、身心靈、二選一、五張十字、關係牌陣、凱爾特十字。可以選擇問題類型（綜合／感情／事業）和是否包含逆位，翻牌後逐張顯示解讀，最後附上整體能量統計。
- **每日一牌**：以當天日期當作亂數種子，所以同一天抽到的牌都一樣。

## 檔案結構
```
index.html
css/style.css
js/data/major.js                    大阿爾克那
js/data/minor-wands-cups.js         權杖、聖杯
js/data/minor-swords-pentacles.js   寶劍、錢幣
js/spreads.js                       牌陣定義（新增牌陣只要在這裡加一筆）
js/app.js                           介面與占卜邏輯
FEATURES.md                         延伸功能調研與後續建議
```
